# Kalbe Tıklar Mısın?

Videodaki iki bölümü tek çalışan web projesinde birleştirilmiş hâli.

## Çalıştırma
1. ZIP'i çıkar.
2. `index.html` dosyasını Chrome/Edge/Firefox ile aç.
3. Kalbe dokun.
4. Mektuptaki `EVET` butonu ikinci animasyona geçer.

İnternet bağlantısı olmadan da çalışır; Google Fonts yüklenemezse sistem yazı tipine düşer.
